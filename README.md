# รายงานสรุปสมาชิกสมาคม · Thai Future Food

เว็บรายงานทะเบียนสมาชิกสมาคม ธีมสีเหลือง-ชมพู

## ทำอะไรได้
- แสดงข้อมูลสมาชิกแต่ละราย: ชื่อบริษัท (ไทย/อังกฤษ), ผู้แทน 1 และ 2, ที่อยู่สำนักงาน พร้อมระบุว่าเป็นสำนักงานใหญ่หรือสาขา, ประเภทสมาชิก (สามัญ/วิสามัญ), ประเภทวิสาหกิจ (S/M/L), ผู้ติดต่อ เบอร์โทร อีเมล เว็บไซต์
- สรุปยอดสมาชิก และกราฟตามประเภทวิสาหกิจ ลักษณะธุรกิจ และจังหวัด
- ค้นหาและกรองตามประเภทสมาชิก ประเภทวิสาหกิจ สำนักงานใหญ่/สาขา และจังหวัด
- คัดลอกอีเมลหรือตารางของรายชื่อที่กรองไว้
- หน้า `#pitch` สำหรับนำเสนอ 1 นาที ตอบ 3 ข้อ พร้อมนาฬิกาจับเวลา

## ทำงานอย่างไร
| ส่วน | ใช้อะไร |
|---|---|
| ฐานข้อมูล | Google Sheets ใน Google Drive ของ admin@thaifuturefood.org (ชีต `Members`) |
| ดึงข้อมูล | Google Sheets connector ของ Claude (`get_values`) ใช้สิทธิ์ของคนที่เปิดดู |
| ล็อกเข้าระบบ | ตรวจอีเมลบัญชี Claude ของคนที่เปิด ต้องเป็น `admin@thaifuturefood.org` |
| โฮสต์ | Claude artifact (claude.ai) |

ข้อมูลสมาชิก**ไม่ได้**อยู่ใน repo นี้ เว็บดึงจาก Google Sheet ตอนเปิดใช้งานเท่านั้น

> **หมายเหตุ:** `index.html` ต้องเปิดผ่าน claude.ai เพราะใช้ runtime ของ Claude (`window.claude`) ทั้งการตรวจอีเมลและการอ่าน Google Sheets
> ถ้าเปิดไฟล์ตรง ๆ หรือเปิดผ่าน GitHub Pages จะติดอยู่ที่หน้าล็อก ไม่มีข้อมูลรั่ว แต่ก็ใช้งานไม่ได้
