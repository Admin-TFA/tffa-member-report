บทที่ 13 · นำเสนอผลงาน

นำเสนอ 1 นาที ตอบ 3 ข้อ

1

แก้ปัญหาอะไร

ก่อนมีเว็บนี้ ทำงานกันยังไง

  • ทะเบียนสมาชิกอยู่ในไฟล์ Excel 37 คอลัมน์ เปิดบนมือถือแทบอ่านไม่ได้
  • หาเบอร์/ผู้แทนของบริษัทหนึ่งต้องเลื่อนหาทีละแถว
  • ส่งไฟล์ต่อกันทางไลน์-อีเมล เวอร์ชันไม่ตรงกัน และข้อมูลติดต่อหลุดง่าย
  • ตอนนี้: ลิงก์เดียว ค้นหา-กรองได้ทันที เห็นเฉพาะ admin
2

ต่อกับอะไรบ้าง

Sheets, Supabase, Connector ไหน

  • Google Drive / Sheets — ไฟล์ "TFFA ทะเบียนสมาชิกสมาคม" เป็นฐานข้อมูล แก้ใน Sheet แล้วเว็บอัปเดตเอง
  • Google Sheets API อ่านข้อมูลด้วยสิทธิ์ Google ของผู้เข้าใช้ ข้อมูลไม่ฝังในหน้าเว็บ
  • Google Sign-In ตรวจอีเมลต้องเป็น admin@thaifuturefood.org
  • GitHub Pages โฮสต์เว็บ เปิดได้ทุกเครื่อง
  • ไม่ใช้ Supabase — ข้อมูล 70 ราย Sheet เพียงพอ
3

จะทำอะไรต่อ

ฟีเจอร์ถัดไป หรือใครจะได้ใช้

  • ฟอร์มเพิ่ม/แก้ไขสมาชิก เขียนกลับลง Sheet
  • แจ้งเตือนต่ออายุสมาชิกภาพ และสรุปรายเดือนส่งอีเมล
  • เพิ่มรายชื่ออีเมลกรรมการที่อนุญาต
  • ผู้ใช้: ฝ่ายทะเบียนสมาคม กรรมการ และทีมจัดงาน
1:00นาทีต่อคน
บทพูด 60 วินาที: "สมาคมมีสมาชิก 70 ราย ข้อมูลเดิมอยู่ใน Excel ที่เปิดบนมือถือแทบไม่ได้ เราย้ายข้อมูลขึ้น Google Drive แล้วทำเว็บนี้อ่านจาก Sheet โดยตรง เข้าได้เฉพาะบัญชี admin ของสมาคม — ค้นชื่อบริษัท ดูผู้แทนทั้งสองคน ที่อยู่ว่าเป็นสำนักงานใหญ่หรือสาขา ประเภทสมาชิก ประเภทวิสาหกิจ และเบอร์ติดต่อได้ในหน้าเดียว ขั้นต่อไปคือฟอร์มแก้ไขข้อมูลและแจ้งเตือนต่ออายุ ให้ฝ่ายทะเบียนและกรรมการใช้ร่วมกัน" — แล้วเปิดเว็บจริงบนมือถือให้ดู ดีกว่าสไลด์ 10 หน้า
